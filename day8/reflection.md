# Web Foundations: Course Reflection

Looking back over the Web Foundations course, the most difficult concept for me to grasp was connecting the front-end to external APIs using JavaScript's `async` and `await`, alongside handling complex DOM manipulation (as seen in Project 2). Moving from static HTML/CSS to asynchronous data flows felt like a steep learning curve. I overcame this by breaking the code down into smaller pieces—first ensuring I could fetch and `console.log` the data correctly, and only then worrying about creating the HTML elements dynamically. Tracing the data step-by-step through the `try/catch` blocks helped solidify my mental model.

Regarding my capstone presentation, the primary feedback I received was to improve the visual hierarchy of my CSS design. Based on this, if I were to improve my capstone, I would restructure my CSS using a clearer Flexbox layout.

Moving forward, I plan to learn more advanced backend development with Node.js. Having built a complete system design and API client from scratch, I feel prepared to tackle this more advanced, specialized tool.
